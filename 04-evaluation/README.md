# Module 4: Evaluation Metrics for Classification

This module covers evaluation metrics for binary classification models, including ROC AUC, precision, recall, F1 score, and K-Fold cross-validation.

---

## 📚 Module Topics

1. **ROC AUC:** Evaluating binary classification ranking quality and numerical feature importance.
2. **Model Training:** Training logistic regression with `DictVectorizer` and measuring validation AUC.
3. **Precision & Recall:** Analyzing classification trade-offs across different decision thresholds.
4. **F1 Score:** Harmonic mean of precision and recall to identify the optimal threshold.
5. **Cross-Validation:** 5-Fold cross-validation using `KFold` to assess model stability.
6. **Hyperparameter Tuning:** Tuning regularization parameter `C` across cross-validation folds.
