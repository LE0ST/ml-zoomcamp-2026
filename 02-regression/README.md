# Module 2: Machine Learning for Regression

This module covers linear regression, setting up a validation framework, evaluating regression models with RMSE, feature engineering, and regularization.

---

## 📚 Module Topics

1. **Linear Regression:** Simple and vector forms of linear regression and the normal equation.
2. **Validation Framework:** Splitting data into train, validation, and test sets.
3. **Model Evaluation:** Root Mean Squared Error (RMSE) metric.
4. **Feature Engineering & Missing Values:** Handling missing data with constant or mean imputation.
5. **Regularization:** Ridge regression to control model weights and handle collinearity.
6. **Model Tuning:** Selecting the best regularization parameter on validation data.
