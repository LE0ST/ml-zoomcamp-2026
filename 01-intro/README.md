# Module 1: Introduction to Machine Learning

This module covers the core concepts of Machine Learning, the lifecycle of a data project using the CRISP-DM methodology, and foundational data science tools (NumPy, Pandas, and Linear Algebra).

---

## 📚 Module Topics

1. **What is Machine Learning?** Differences between rule-based systems and machine learning.
2. **Supervised Learning:** Features, target variables, and problem formulation.
3. **CRISP-DM:** Standard framework for structuring data science and ML projects.
4. **Model Selection:** Basic model comparison and validation workflow.
5. **Data Analysis Tools:**
   - **NumPy** fundamentals and vectorized operations.
   - Essential **Linear Algebra** (matrices, transpositions, matrix inversion).
   - Tabular data manipulation with **Pandas**.
