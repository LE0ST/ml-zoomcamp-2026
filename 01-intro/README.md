# Módulo 1: Introducción a Machine Learning

Este módulo cubre los fundamentos conceptuales de Machine Learning, el ciclo de vida de un proyecto de datos con la metodología CRISP-DM y la preparación de las herramientas básicas (NumPy, Pandas, Álgebra Lineal).

---

## 📚 Temas del Módulo

1. **¿Qué es Machine Learning?** Diferencias entre sistemas basados en reglas y aprendizaje automático.
2. **Aprendizaje Supervisado:** Características (*features*), variable objetivo (*target*) y formulación de problemas.
3. **CRISP-DM:** Metodología estándar para estructurar proyectos de ciencia de datos.
4. **Selección de Modelos:** Comparación básica y flujo de validación.
5. **Herramientas de Análisis de Datos:**
   - Fundamentos de **NumPy** y operaciones vectorizadas.
   - Operaciones de **Álgebra Lineal** esenciales (matrices, transposición, inversión).
   - Manipulación de datos tabulares con **Pandas**.
