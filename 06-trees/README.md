# Module 6: Decision Trees and Ensemble Learning

This module covers tree-based models for regression, including decision trees, random forests, feature importance, and gradient boosting with XGBoost.

---

## 📚 Module Topics

1. **Decision Trees:** Decision trees for regression, finding split features, and tree structure inspection.
2. **Random Forest:** Ensemble learning, training random forests for regression, and measuring validation RMSE.
3. **Tuning Forest Size:** Analyzing the effect of `n_estimators` on convergence and validation score.
4. **Tuning Tree Depth:** Evaluating `max_depth` across multiple forest sizes to find optimal tree complexity.
5. **Feature Importance:** Extracting and ranking feature importances based on impurity reduction (gain).
6. **Gradient Boosting (XGBoost):** Training gradient boosted trees with `xgboost` and tuning the learning rate parameter (`eta`).
